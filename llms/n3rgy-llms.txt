# n3rgy

> n3rgy data limited is a United Kingdom smart-energy data platform, owned by Smart Metering Systems Ltd and registered in England (No. 11712674). It sits between Great Britain's mandated smart-metering infrastructure — the DCC network, SMETS2 home area networks (HANs) and the ESME/GSME electricity and gas meters behind them — and businesses that want to read from it. A business can collect consumption, production and tariff data for a property (addressed by MPAN/MPRN, collectively MPxN) once the occupant has granted consent, without itself becoming a DCC user.

Generated by API Evangelist on 2026-07-27. n3rgy publishes no llms.txt of its own (probed: 404 on both API hosts, MkDocs 404 shell on the docs host).

## What is actually available

- **Documentation: fully public.** The MkDocs developer guide is anonymously readable, and the complete OpenAPI 3.0.1 contract for the Customer Service API V2 (26 operations, 47 schemas) is downloadable by anyone.
- **Data: closed.** Both declared servers answer HTTP 403 to anonymous callers. A live key must be enabled by the n3rgy back office after a business sign-up; there is no self-serve key issuance.
- **Two authorisation layers above the key.** Consent-bearing operations also require an ACTIVE end-customer consent for the HAN behind the supplied MPxN (403 "Consent for the given MPxN not found."). Frequency-control operations additionally require an account permission to change update frequencies.
- **No consumer API.** The formerly public consumer API (consumer-api.data.n3rgy.com) has been withdrawn — n3rgy's own GitHub org states "unfortunately the consumer API is not longer available (it's a regulatory thing)". Consumers now have only the web Consumer Portal.
- **No open market data.** n3rgy publishes no grid, generation-mix, settlement or carbon-intensity data. That is a different part of the GB stack (NESO, Elexon, DNO portals).
- **No energy data standard.** The contract is a proprietary schema expressed in GB smart-metering vocabulary. There is no Green Button/ESPI, no Consumer Data Right, no IEC CIM, no IEEE 2030.5, no OpenADR.

## APIs

- [n3rgy Customer Service API V2](https://customer-api-user-manuals.data.n3rgy.com/): Consent-scoped smart-meter data. List consented properties, discover available utilities and reading types, retrieve half-hourly consumption/production/tariff data, control meter update frequency, look up MPxNs by identifier or UK address, read the DCC device inventory, force on-demand meter fetches, configure push notifications, and upload data for non-SMETS devices. Live host https://api-v2.data.n3rgy.com, sandbox host https://api-v2-sandbox.data.n3rgy.com.

## Getting access

1. Read the developer guide anonymously at https://customer-api-user-manuals.data.n3rgy.com/ — no login required.
2. Complete the business sign-up at https://data.n3rgy.com/business-sign-up for the free sandbox tier.
3. Contact n3rgy (https://www.n3rgy.com/business/) to have a live key enabled by the back office. Pricing tiers are Standard / Scale / Volume.
4. Obtain end-customer consent per property before any consent-bearing endpoint returns data.
